Первый запуск ведущего

Игра и помощник уже в EXE. Изолированный Python и Windows-компоненты нужно загрузить один раз. Только с python.org и PyPI, с проверкой контрольных сумм. Системный Python не изменяется.

Прямой HTTP-доступ не шифруется. Текущий игровой протокол рассчитан на доверенную компанию, а не на открытый публичный сервис. Не публикуйте адрес для всех и не отключайте брандмауэр целиком.
