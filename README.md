# ☣️ Настольная игра «БУНКЕР» (Онлайн для друзей)

Бесплатный полнофункциональный аналог популярной настольной игры «Бункер». Создан специально для комфортной игры с друзьями через голосовую связь в **Discord** без подписок, ограничений по игрокам или рекламы.

---

## 🚀 Как запустить игру

1. Дважды кликните по файлу **`start_game.bat`** в папке проекта.
2. Скрипт автоматически:
   - Проверит окружение Python и библиотеки.
   - Запустит сервер.
   - Откроет игру в вашем браузере по адресу `http://localhost:64738`.
3. В окне консоли и на главном экране вы увидите ваш внешний IP:
   - **Для друзей в Discord**: нажмите кнопку **«📋 Ссылка в Discord»** (или скопируйте ссылку вида `http://<ВАШ_ВНЕШНИЙ_IP>:64738?room=XXXX`).
   - Друзья могут открыть эту ссылку на **смартфонах**, планшетах или во второй вкладке браузера на ПК.


---

## 🎮 Как играть

1. **Создание лобби**:
   - Ведущий (Хост) нажимает «Открыть Шлюз и Создать Комнату».
   - Получает 4-значный код комнаты (например, `ABCD`) и ссылку для Discord.
   - Друзья вводят свои имена и код комнаты на своих смартфонах/компьютерах.
2. **Старт игры**:
   - Ведущий настраивает количество спасительных мест в бункере (по умолчанию половина игроков) и нажимает «Начать игру».
   - Система случайно выбирает сценарий **Глобальной Катастрофы** (ядерная зима, зомби-вирус, падение астероида, восстание ИИ и др.), характеристики бункера и генерирует уникальные секретные карты каждому игроку:
     - 💼 **Профессия** (со стажем работы)
     - ❤️ **Здоровье** (болезни, иммунитет, особенности)
     - 🧬 **Биология** (пол, возраст, способность к деторождению, телосложение)
     - 🎯 **Хобби**
     - 🎒 **Багаж** (полезные или неожиданные предметы)
     - 📜 **Факт из биографии**
     - 🃏 **Специальная карта действия** (лечение, обмен вещами, право вето, дополнительное койко-место и др.)
3. **Раунды и защитные речи**:
   - В каждом раунде игроки по очереди держат речь (с таймером 45 секунд) и вскрывают одну из карт на своем смартфоне.
   - Карта сразу с анимацией и звуковым эффектом переворачивается на общем табло бункера.
4. **Дебаты**:
   - Включается общий таймер дебатов. Игроки спорят и доказывают в Discord, почему именно они заслуживают спасения.
5. **Голосование**:
   - Игроки со смартфонов тайно голосуют за изгнание одного из кандидатов.
   - Система подсчитывает голоса и определяет изгоняемого игрока.
   - Игроки со спецкартами (например, «Право Вето») могут аннулировать изгнание.
6. **Финал игры**:
   - Когда количество оставшихся кандидатов сравнивается с вместимостью бункера, двери закрываются!
   - Алгоритм оценивает состав колонии (наличие врачей, инженеров, агрономов, репродуктивный баланс) и генерирует итоговый эпилог: **смогли ли вы выжить и возродить цивилизацию?**

## 👑 Права и возможности Ведущего (Хоста)

У ведущего прямо на экране расположена панель управления:
- ⏸️ **Пауза / Возобновление таймера** — в любой момент можно остановить время для длинных дискуссий.
- ⏱️ **+30 сек** — добавить дополнительное время выступающему или на дебаты.
- 🔄 **Повторные дебаты** — перезапустить раунд споров при спорных ситуациях.
- 🗣️ **К дебатам** / 🗳️ **Начать голосование** — принудительная смена фазы по желанию хоста.
- 🚨 **Сирена тревоги** — включает атмосферный звуковой сигнал тревоги у всех участников (отличный способ привлечь внимание в Discord!).
- ❌ / ✨ **Ручное изгнание / Помилование** — хост может вручную исключить или вернуть любого игрока при необходимости.

---

## 🔊 Звуковые эффекты
В игру встроен процедурный синтезатор звуков на Web Audio API (сирена тревоги, механический затвор гермодвери, переворот карт, тиканье таймера, звук изгнания). Звук можно включить или выключить кнопкой в правом верхнем углу.
