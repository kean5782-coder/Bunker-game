# Бункер

Игра для компании: мир накрылся, мест в бункере мало, а у вас костюм хот-дога
и сомнительный стаж работы. Обсуждайте персонажей, спорьте и решайте,
кого оставить. Главная цель — весело провести время.

Ветка **main** содержит актуальную версию V4.6 с обновлённой колодой,
полным рандомом и девятью спецкартами для речей.
Прежняя версия репозитория целиком сохранена в ветке
[Old-version](https://github.com/kean5782-coder/Bunker-game/tree/Old-version).

## Запуск на Windows

1. Скачайте [Bunker.exe](https://github.com/kean5782-coder/Bunker-game/raw/refs/heads/main/Bunker.exe).
2. Рядом сохраните [STOP_BUNKER.bat](https://github.com/kean5782-coder/Bunker-game/raw/refs/heads/main/STOP_BUNKER.bat)
   и [STOP_BUNKER.ps1](https://github.com/kean5782-coder/Bunker-game/raw/refs/heads/main/STOP_BUNKER.ps1).
3. Если прежний сервер ещё работает, закройте его через `STOP_BUNKER.bat`.
4. Запустите `Bunker.exe`, создайте комнату и отправьте друзьям ссылку,
   которую покажет помощник. Игроки подключаются через браузер.

Ведущему нужна Windows x64. При первом запуске нужен интернет для загрузки
компонентов Python; устанавливать Python вручную не требуется. Игра и медиа
уже встроены в EXE. Для подключения через интернет настройте один из способов,
предложенных помощником: локальная ссылка работает только внутри вашей сети.

Закрытие вкладки браузера не останавливает сервер. После игры запустите
`STOP_BUNKER.bat`, чтобы завершить сервер и фоновый помощник.

## Что изменилось

- **«Полный рандом» включён по умолчанию.** Нет обязательного врача, инженера
  или гарантированно полезного набора вещей. Режим «С подстраховкой» доступен
  отдельно в лобби.
- **631 карточка персонажей в девяти категориях.** Простые названия,
  переносимый инвентарь, нелепые привычки и истории для споров.
- **Девять новых спецкарт для речей:** «Теперь ты так разговариваешь»,
  «Слово прилипло», «Я только спрашиваю», «Короче», «Это не я»,
  «Продай себя», «Всё в рифму», «Уважаемый огурец» и «Суфлёр».
  Правило действует на одно выступление; участники исполняют его сами.
- **Исправлены тексты и свойства карточек.** Лечение меняет описание здоровья,
  страх клоунов тоже можно вылечить, а дождевик больше не спасает от потопа.

Подробнее о правилах, подключении и звуке — в [README_V4_6.md](README_V4_6.md).
