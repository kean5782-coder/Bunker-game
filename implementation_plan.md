## 1. 🎯 Геймплейные улучшения

### 1.1 Система альянсов и переговоров
> Сейчас игроки могут только голосовать и раскрывать карты. Нет механики для формирования коалиций внутри игры.

#### [NEW] Тайные сообщения / Альянсы
- Добавить возможность **тайных переговоров 1-на-1** через WebSocket (шёпот): игрок может во время дебатов отправить приватное сообщение другому игроку
- Альянс из 2-3 игроков, которые могут **координировать голосование** (видят, за кого проголосовал союзник в реальном времени)
- Ведущий в логе видит факт создания альянса (без содержания переписки)

#### [NEW] Торговля между игроками
- Разрешить **обмен одной картой** (багаж↔багаж или хобби↔хобби) с согласия обоих игроков в фазе дебатов
- Это уже частично реализовано через спецкарту `swap_baggage`, но стоит расширить как полноценную механику

### 1.2 Настраиваемые правила для ведущего

#### [MODIFY] [`game_engine.py`](file:///f:/Бункер/server/game_engine.py)
Сейчас параметры жёстко зашиты:
- `speech_duration_sec = 45` (строка 101)
- `debate_duration_sec = 90` → фактически 60 сек на игрока (строка 448)
- Лимит вскрытия: 1 в R1, 2 в R2+ (строка 405)

**Предложение**: создать `GameSettings` dataclass и передавать из лобби:
```python
@dataclass
class GameSettings:
    speech_duration: int = 45
    debate_duration_per_player: int = 60
    voting_duration: int = 60
    reveals_round_1: int = 1
    reveals_round_2_plus: int = 2
    threshold_percent: float = 33.0
    enable_alliances: bool = False
    enable_trading: bool = False
    max_rounds: int | None = None  # Авто-финал после N раундов
```

### 1.3 Система достижений и статистики

#### [NEW] Постигровая статистика
- **MVP голосований** — кто точнее всего голосовал (совпадение с большинством)
- **Мастер блефа** — кто последний вскрывал «бесполезную» карту и остался
- **Кровожадный** — кто чаще всех голосовал за изгнание (не воздерживался)
- Сохранять историю игр в `localStorage` с красивым экраном истории

### 1.4 Режимы игры

#### [NEW] Быстрый режим «Метеорит»
- 3-5 игроков, 1 место в бункере, 20 сек на речь, все карты открыты кроме спецкарты и факта
- Идеально для быстрых игр в перерыве

#### [NEW] Режим «Двойной агент»
- 2 предателя вместо 1, но они **не знают** друг друга
- Если оба выживают — оба проигрывают (нужен баланс)

### 1.5 Система выборов и объявлений

#### [NEW] «Последнее слово» изгнанного
- Перед окончательным изгнанием дать 15 секунд на **последнюю речь** с возможностью вскрыть все оставшиеся карты
- Это создаст драматичные моменты и новые данные для оставшихся

## 3. ⚖️ Балансные улучшения

### 3.1 Система весов и тегов для профессий

> Сейчас `PROFESSIONS` — это плоский массив из ~60 записей без числового веса. Профессия «Врач-хирург» и «Инспектор по парковкам» выбираются с равной вероятностью `random.choice()`.

#### [MODIFY] [`deck_data.py`](file:///f:/Бункер/server/deck_data.py)

**Предложение**: Добавить числовые поля к каждой профессии:
```python
{
    "name": "Врач-хирург",
    "tag": "medicine",
    "weight": 85,           # Общая ценность 0-100
    "synergy_tags": ["science", "medicine"],  # С кем синергия
    "anti_tags": [],         # С кем конфликт
    "survival_base": 12,     # Базовый бонус к survival_percent
    "rarity": "common",      # common/uncommon/rare — влияет на вероятность выпадения
}
```

**Гарантированный баланс раздачи:**
- При генерации колоды (`generate_game_deck`) гарантировать:
  - Минимум 1 профессия тега `medicine`
  - Минимум 1 профессия тега `engineering`
  - Не более 2 профессий тега `useless` на 8+ игроков
  - «Бесполезные» профессии выпадают максимум 30% игроков

### 3.2 Синергия и антагонизм между игроками

#### [MODIFY] `evaluate_survival()` 
Сейчас `evaluate_survival()` — это линейное сложение очков. Нужна система синергий:

- **Синергия**: Врач + Фармацевт = +15% к выживаемости (вместо +10% + +10%)
- **Антагонизм**: 2 игрока с `useless` тегом без инженера = -20% (нехватка критических навыков)
- **Критический порог**: Если нет ни одного инженера/механика и бункер имеет `threat` — автоматический -30%

### 3.3 Баланс состояний здоровья

#### [MODIFY] [`deck_data.py`](file:///f:/Бункер/server/deck_data.py) — раздел `HEALTH_CONDITIONS`

### 3.4 Баланс спецкарт

> Текущие спецкарты сильно разнятся по силе:
> - `extra_bunk` (доп. койко-место) = **game-changing** — изменяет условие победы
> - `silence_player` (запрет речи) = **почти бесполезна** в онлайн-формате через Discord

#### [MODIFY] [`deck_data.py`](file:///f:/Бункер/server/deck_data.py) — спецкарты

| Карта | Текущая сила | Проблема | Предложение |
|-------|-------------|----------|-------------|
| `extra_bunk` | S-tier | Слишком сильная, авто-вин | Ограничить: не более 1 за игру; доп. место = -5% к выживаемости (теснее) |
| `veto_vote` | A-tier | Справедливая | Оставить, добавить кулдаун 1 раунд |
| `silence_player` | D-tier | В Discord говорят голосом | Заменить на «Заморозка хода»: пропуск вскрытия карт на 1 ход |
| `heal_illness` | B-tier | Нормальная | Добавить визуальный эффект исцеления |
| `secret_peek` | C-tier | Информация не даёт прямого преимущества | Показывать подсмотренную карту **с возможностью объявить вслух** (раскрыть всем) |

### 3.5 Баланс системы событий

> Текущая система событий (`calculate_event_odds`) использует масштабирование `int(raw_val * 0.45)` для бонусов, что ограничивает бонусы до +5..+12%. Штрафы при этом +8..+16%.

#### [MODIFY] [`deck_data.py`](file:///f:/Бункер/server/deck_data.py) строки 1700-1710

- Бонусы от правильных профессий ощущаются слабо — увеличить множитель с 0.45 до 0.60
- Добавить **критические удачи** (натуральная 1 на d100 = авто-успех) и **критические провалы** (натуральная 100 = авто-провал с удвоенным уроном)
- Добавить **кумулятивный эффект**: каждый последовательный провал увеличивает шанс следующего успеха на +5% (пити-система)

### 3.6 Значимость изгнанных на поверхности

> Сейчас `is_exile_alive_on_surface()` — хорошая идея, но изгнанные слабо влияют на финал.

#### [NEW] Механика «Вендетта изгнанных»
- Каждый живой изгнанник на поверхности **один раз за игру** может проголосовать за «саботаж» — снижение шанса на 5% при финальном подсчёте
- Это мотивирует изгнанных оставаться в комнате до конца и создаёт драму
